# Cerebr-Nico-V1.0.49
CerebroNico es una IDE local con agente autónomo de ingeniería de software: planifica, edita con precisión quirúrgica, ejecuta terminal, Git y verifica en sandbox (:3500). Integra memoria persistente Hindsight, auditoría de calidad X10, creador web sin frameworks, exportación de PDF/DOCX/XLSX y soporte para Ollama o modelos en la nube (Gemini/ZAI).
